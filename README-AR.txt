AYLA GYNO — نسخة Student العادية — الإصدار 1.0.1

الواجهة باللغة الإنجليزية، والثيم وردي هادئ مع وضع داكن.
لا يوجد نظام حسابات أو اشتراكات أو دفع في هذه النسخة.
تُحفظ الأسئلة والصور والتقدم محلياً في المتصفح، ولا توجد مزامنة سحابية.

النشر على GitHub Pages:
فك ضغط حزمة هذه النسخة، ثم ارفع الملفات الموجودة داخلها مباشرة إلى جذر المستودع.
يجب أن يظهر index.html في جذر مصدر النشر، وليس داخل مجلد خارجي إضافي.
اختر Settings → Pages → Deploy from a branch → main → / (root).
تستخدم هذه النسخة روابط نسبية لتعمل أيضاً داخل مسار مستودع GitHub.
لا ترفع ملف ZIP وحده؛ ارفع محتوياته بعد فك الضغط.

التصنيفات:
مصدرها ملف Dewhurst 9e الذي زوّد به صاحب المشروع، مع أقسام Obstetrics وGynaecology.
لإعداد أسئلة بالذكاء الاصطناعي، نزّل دليل التصنيفات من Settings وأرفقه مع المصدر والبرومبت.

العمل دون إنترنت:
افتح الموقع مرة عبر HTTPS وانتظر اكتمال تحميل ملفات التطبيق، ثم أعد فتحه لتفعيل التخزين دون اتصال.
استورد بنك الأسئلة قبل الدراسة. ملفات التطبيق لا تتضمن أسئلة أو صوراً طبية جديدة.

حافظ على نسخة احتياطية قبل حذف بيانات المتصفح أو تغيير رابط الاستضافة.
نسخة AYLA مستقلة عن نسخة ENT الأصلية؛ لا تُنقل بيانات ENT تلقائياً إليها.
